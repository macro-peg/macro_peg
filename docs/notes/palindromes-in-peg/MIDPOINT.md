# An ordinary PEG component for both midpoint cuts

`generated/midpoint.peg`, generated by `midpoint_peg.py`, has these contracts
on every binary suffix of length `n`, starting at position `i`:

| Rule | Returned position |
| --- | --- |
| `HalfFloor` | `i + floor(n/2)` |
| `HalfCeil` (also `H`) | `i + ceil(n/2)` |

For even `n` the cuts meet. For odd `n` the one character between them is the
middle character. Both return immediately at EOF. The grammar has **9,949
rules and 269,633 bytes**, independently of input length. Construction takes
about 0.3 seconds on the current host (0.42 seconds including interpreter
startup, peak RSS 25,284 KiB in the recorded run). There is no input expansion, injected
delimiter, length parameter, semantic action, or macro in the emitted rules.

This is **not a PAL recognizer**. Its standalone `S` wrapper accepts all
binary strings, including `ab`. A pointer to the midpoint does not itself
compare the halves or make a consumed prefix available as a continuation.

## Construction and invariant

The source has one transition per original character. It uses the existing
persistent FIFO equations and two finite control bits. At arrival `n`, enqueue
the new input-node address and run three FIFO rotation units. Observe the
front; pop it if `n` is even. Alphabet data does not affect this schedule.

After arrival `n`, the dequeued addresses are exactly `1 .. floor(n/2)` in
order, and the remaining queue contains `floor(n/2)+1 .. n`. The last dequeued
address is `floor(n/2)`; before the optional pop, the offered front is
`ceil(n/2)` in both parity cases. On the first arrival, the saved lower address
is the initial sentinel, node 0. Two pointer fields store these addresses.

The queue's rotation schedule has a fixed bound. While idle, its counter is
`front_length - rear_length`. Between service rounds there is at most one pop
and one push, so a rotation starts with `F < R <= F+2`. Reversing both old
lists, switching phase, and copying the live old front takes at most
`R+1+F <= 2F+3` units. Concurrent pops can reduce the copies. Before pop
number `F+1` could need the replacement front, `3(F+1) >= 2F+3` units run.
This includes the empty-front case `F=0, R<=2`.

A finished rotation has a nonnegative balance, so another rotation cannot
start partway through that same service round. If completion takes `r`
rounds, at most `r-1` new arrivals and `r-1` pops occur since its start. The new
front has at least `F+R-(r-1)` items and the new rear at most `r-1`. Since
`r <= ceil((F+R+1)/3)`, the former is at least the latter. Inductively, each
rotation starts at the first unit of a round, as the deadline argument uses.
The queue's `m` counter discards already popped front entries during copying;
its `c` counter restores the idle balance by adding two per reversed rear
entry. This is a bound from the queue operations, not a measured budget.

Scaffold-to-PEG translation reverses the source input. A pointer from node
`n` to node `j` becomes a rule consuming `n-j` characters. Thus the lower
source address becomes `HalfCeil`, and the upper becomes `HalfFloor`. The EOF
alternatives handle the initial sentinel. This explains the reversed names.

The compiler removes constant null fields and equations unreachable from
these two pointer queries. The state-test source retains its invariant
monitor. No finite input set is used to specialize the grammar.

## Checks and reproduction

```sh
cd docs/notes/palindromes-in-peg
python3 midpoint_peg.py generated/midpoint.peg
python3 -m unittest test_midpoint_peg test_phase_peg -v
```

The tests check both exact node identities through 1,024 arrivals and check
that the invariant monitor stays clear. The PEG is checked on all 127 binary
strings through length 6, on odd/even boundary lengths through 257, and after
a consumed prefix. `Grammar.parse_prefix` exposes the returned position;
whole-word acceptance alone cannot check these contracts.

For an independent ordinary PEG evaluator, append:

```peg
ProbeCeil = HalfCeil "b" "a"* !.;
ProbeFloor = HalfFloor "b" "a"* !.;
```

Put a unique `b` at, before, and after the predicted cut. Each probe accepts
exactly when that marker is at its returned position. Run the Rust evaluator
with `--start ProbeCeil` or `--start ProbeFloor`, using original strings and
no `--repeat`. The marker belongs to these tests, not to the component.
The executed Rust checks cover 138 cases per cut, 276 in total, through
length 257; all agree. The log is retained at
`/home/mizushima/.codex/artifacts/pal-peg/midpoint-rust.log`.
The two midpoint tests and eight phase/interpreter tests passed in 24 seconds.
`sbt test` also succeeded using its cache (zero Scala tests re-executed).

## Remaining PAL work

The midpoint operation need not be restricted to power-of-two lengths or
obtained through the large Galil translation. The comparison problem remains:
calling a midpoint rule and then a right-half rule loses access to the
left-half symbols unless another invariant carries the necessary information.
A PAL construction must explain that invariant in ordinary PEG terms and
test its actual recognition language.
